# Workspace Rules for ASF Inventory Management System

## MANDATORY DESIGN SYSTEM RULE

Before implementing, editing, or modifying ANY page, layout, form, table, or UI component in this codebase, you MUST:
1. Read `d:\ASF\DESIGN_SYSTEM.md` to review the authoritative color palette, typography, layout structures, and Material UI guidelines.
2. Strictly enforce the ASF Deep Forest Green (`#1e5631`) & Muted Accent Green (`#2d6a4f`) portal color scheme across all elements.
3. Use Material UI v5 components exclusively (`@mui/material`, `@mui/icons-material`).
4. Keep table headers styled with Deep Forest Green background (`#1e5631`) and white text (`#ffffff`).
5. Keep all dialogs, forms, cards, and navigation items synchronized with `DESIGN_SYSTEM.md`.
